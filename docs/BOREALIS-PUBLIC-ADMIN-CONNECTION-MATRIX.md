Immediate public update means intended post-commit cache/path revalidation, which remains unverified by real saves.

## How to verify publication safely next

For each connected row, use synthetic isolated data: capture public value A, save draft B, assert public stays A and authorized preview sees B; publish, assert B appears in all relevant list/detail/home/footer/SEO/language consumers; archive/restore and verify links/media/error handling. Inject a write/cache invalidation failure and test roles directly at API/database/storage boundaries. Test more than the editor's success message. No such writes were authorized on production during this audit.

Hardcoded safety limits, SQL pricing authority, role definitions, credentials and deployment controls should remain technical. Owner content controls should cover real editorial text/media/links and business policies only when their behavior is implemented and tested. See F01–F27 in [roadmap](BOREALIS-REMEDIATION-ROADMAP.md) for exact corrective criteria.
